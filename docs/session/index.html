LEMON · 90-MIN TUTORING SYSTEM

家教执行系统

每次家教先有计划，再执行、验证和复盘。课内作业最多 45 分钟；后 30 分钟固定为一个主项目 + 一个维护项目。

02 · PLAN WITH LEMON

5 分钟不是老师写计划，而是和 Lemon 完成一次“开工确认”

老师应在课前已经想好候选任务；这 5 分钟只负责让 Lemon 知道今天做什么、参与选择，并真正开始。

① 今天必须做什么？老师用 30–60 秒说清今天的课内任务和两个课外候选项目，不讲大道理。
② Lemon 选顺序“今天这些要完成，你想先语文还是数学？”只给真实可兑现的选择。
③ 确认卡住怎么办让 Lemon 自己说一次：“卡住我会告诉你哪里不会 / 我需要一个提示。”
④ 确认结束点并开工“课内最多 45 分钟，中间休息 5 分钟；做完计划就结束。现在第一步是什么？”
5 分钟的完成标准不是“聊完了”，而是 Lemon 能回答：今天做什么 → 先做什么 → 卡住怎么办 → 做到哪里结束 → 现在第一步是什么。
老师可以直接这样说： “今天先把必须的作业列一下：____、____、____。 课内最多做 45 分钟。 后面我们从 ____ 和 ____ 里做一个主项目，再维护一个小项目。 你想先做哪科？ 如果中间卡住，你准备怎么告诉我？ 今天这些完成就结束，不临时加。 好，现在第一步是什么？你来开始。”
03 · PROJECT POOL

每次只选 1 Main + 1 Maintenance

不要每天把背单词、阅读、课文、数学、听写、书写全部塞进去。

CHINESE

语文

  • 课文：朗读 → 生词 → 主要内容 → 必要背诵
  • 阅读：读题 → 定位 → 证据 → 完整回答
  • 听写：当前字词 → 找错 → 修复 → 延迟抽查
  • 书写：真实错字 / 笔顺
MATH

数学

  • 数感 / 口算：凑整、拆分、运算律
  • 计算：一个明确类型
  • 问题解决：条件 → 关系 → 算式 → 检查
  • Verify：换一道相近题独立完成
ENGLISH

英语

  • Vocabulary：本周核心词汇 + 随机抽查
  • Reading / PU：一个明确 section
  • 听说：短输入 + 真实输出
  • 书写：四线三格、字母位置、单词间距

08 · WEEKLY REVIEW

每周只看 4 个信号

Start计划后多久开始第一步？
Interrupt成人提醒 / 打断是否减少？
Self-report能否主动说具体卡点？
Resume出错或情绪后多久能继续？
每周只调整一个最值得改的点。每获得一个能力，就删除一个支架。
