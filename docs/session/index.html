LEMON · 90-MIN TUTORING SYSTEM

家教执行系统

每次家教先有计划，再执行、验证和复盘。课内作业最多 45 分钟；后 30 分钟固定为一个主项目 + 一个维护项目。

01 · SESSION

固定 90 分钟骨架

课内作业不能无限吞掉整个家教时间。

Verify & Close

验证、记录、结束

45 分钟到点，未完成就记录“剩多少 + 为什么”，不自动继续占用后续全部时间。
02 · PROJECT POOL

每次只选 1 Main + 1 Maintenance

不要每天把背单词、阅读、课文、数学、听写、书写全部塞进去。

CHINESE

语文

  • 课文：朗读 → 生词 → 主要内容 → 必要背诵
  • 阅读：读题 → 定位 → 证据 → 完整回答
  • 听写：当前字词 → 找错 → 修复 → 延迟抽查
  • 书写：真实错字 / 笔顺
MATH

数学

  • 数感 / 口算：凑整、拆分、运算律
  • 计算：一个明确类型
  • 问题解决：条件 → 关系 → 算式 → 检查
  • Verify：换一道相近题独立完成
ENGLISH

英语

  • Vocabulary：本周核心词汇 + 随机抽查
  • Reading / PU：一个明确 section
  • 听说：短输入 + 真实输出
  • 书写：四线三格、字母位置、单词间距

05 · UNFINISHED

未完成必须分类

不会知识或方法断点
执行停顿会做但中途停顿、走神
作业量大正常速度下 45 分钟做不完
书写慢 / 其他具体摩擦单独记录

07 · WEEKLY REVIEW

每周只看 4 个信号

Start计划后多久开始第一步？
Interrupt成人提醒 / 打断是否减少？
Self-report能否主动说具体卡点？
Resume出错或情绪后多久能继续？
每周只调整一个最值得改的点。每获得一个能力，就删除一个支架。
