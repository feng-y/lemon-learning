LEMON · DAILY LEARNING

今天，一起把学习做好。

先看每周任务池，成人判断今天做什么；再和 Lemon 约定怎么学、什么时候结束；学习时一起讨论、练习、反馈，最后兑现约定。这是一个完整的学习过程，不是几个互不相干的计划。

从每周任务池，安排今天

成人先判断哪些必须完成，哪些可以调整。Lemon 参与选择顺序，但不独自承担全部规划。

    书写训练 · 只占用有余量的时间

    中文逐步从50字走向500字；英文从短行、短段逐渐增加。不是每天额外抄500字，也不是因为做得快临时加量。

    按约定互动学习

    60～90分钟是总时段，包含讨论、示范、独立尝试、休息和回顾；不是一场闷头写作业的考试。

    交流想法
    成人引导

    家教和家长使用同一种方式

    看见卡点，先听 Lemon 怎么想，必要时示范一步，再交回给他尝试。不替他答完整题，也不强制每做一题就来验收。连续练习从能胜任的几分钟开始，根据状态调整。

    今天我们怎么约定

    成人决定任务边界，Lemon 选择先做什么、自己负责什么，以及希望获得的奖励。

    今日已选任务0/3 主任务
    可用时间0分钟

    估计时间不是硬性考核。留出教学讨论与休息。

    已选任务若超出时间容量，应由成人减量或重新安排。学校必交的剩余任务另外说清楚，不能要求 Lemon 用无限延长的时间“负责”。

    当次辅导，只记住一个原则

    成人搭支架，让 Lemon 真正完成自己的那一步；做到了就兑现结束与奖励。

    成人不需要全程监考，也不等于完全放手。先陪他把困难说清楚、找到方法，再观察哪些步骤能够逐渐交还给他。

    按需参考，不占用今天的操作路径
