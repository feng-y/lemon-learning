LEMON · LONG-TERM LEARNING SYSTEM

帮助 Lemon 逐渐成为能自己学的人

目标不是多学一点、管得更细，而是通过家长、家教和 AI 的临时支架，让真实学习逐渐形成基础、方法、耐力、自我效能与自主学习能力。

当前阶段2026 秋 · 四年级上｜语文 人教四上 · 数学 北师大四上 · 英语 PEP 四上 + Power Up 3

01 · 目标

长期目标：成人支架逐渐退出

最终不是 Lemon 更服从，而是越来越能自己判断和推进学习。

基础扎实与自动化

字词、计算、词句等基础可靠，减少低层认知负担。

方法、效率与耐力

会拆任务、找卡点、选方法、检查结果，并能面对适度困难。

兴趣、自我效能与自主

知道“我哪里不会、我有办法解决”，最终能自己回答学什么、怎么学、是否学会。

02 · 当前问题

当前四个主要阻塞

不统一解释成“不自律”，分别看行为、技能、情绪与学习认知。

启动慢 / 作业拖拉

看到任务后迟迟不进入第一步，需要成人多次推动。

看：开始耗时、提醒次数
书写动作不稳定

中文笔顺；英文四线三格、字母上下位置、单词间距。

看：能否独立复现正确动作
学习情绪 / 课外抵触

部分能力在进步，但学习感受没有同步改善。

看：负担、难度、重复、课堂方式
学习认知不足

还不能稳定规划任务、发现卡点、选择方法、判断是否完成。

看：成人是否可以减少介入
03 · 当前处理

先减少摩擦，再训练完整学习闭环

能力训练嵌入真实作业与课程，不额外叠加一套“自律训练”。

1
成人先理顺任务

少数重点、明确边界、一次只看当前一项。

2
落到第一步

不是“认真一点”，而是明确现在具体做什么。

3
一次教一个核心动作

先试 → 找断点 → 示范 → 自己做 → 新任务验证。

4
进步换来支架减少

会了减少重复，能自己做就成人后退，完成后不临时加量。

当前两周重点
  • 保持必要学习质量，不自动加量。
  • 减少一处真实低价值负担，释放时间不立即换成新训练。
  • 观察课外抵触发生在哪个具体场景。
  • 任务已经清楚仍抵触时，检查课程本身而不是继续催。
  • 有限自主必须真实兑现。
04 · 各学科

教材是主线，能力结构是长期目标

不靠题量证明进步；围绕真实掌握和长期能力组织。

语文 · 人教四上

字词 → 积累 → 课文理解 → 阅读 → 表达写作
  • 字词关注认读、正确笔顺/字形、词义和易错点。
  • 阅读训练定位、证据和完整回答。
  • 写作先做到有内容、顺序清楚、有具体细节。
  • 当前书写重点是真实错字与笔顺，不大量罚抄。

数学 · 北师大四上

数与运算 → 运算律 → 数量关系 → 几何空间 → 数据
  • 第一主线：大数 → 整数乘法 → 运算律 → 数量关系。
  • 拆分口算、竖式、分配律放进同一个知识结构。
  • 长期关注数感、运算感、计算、空间、建模与问题解决。
  • 少量有目的训练暴露盲点，再针对性修复。

英语 · PEP + PU3

语音 → 词汇 / Chunk → 句型 → 听说读写 → 表达
  • PEP 保证校内主线，PU3 做更丰富的听说读拓展。
  • 当前优先：听得懂 → 说得出 → 读得懂 → 能写基本内容。
  • 规则从真实句子和语境里逐渐抽象。
  • 当前书写重点：四线三格、字母上下控制、单词间距。
