LEMON · LONG-TERM LEARNING SYSTEM

帮助 Lemon 逐渐成为能自己学的人

目标不是多学一点、管得更细，而是通过家长、家教和 AI 的临时支架，让真实学习逐渐形成基础、方法、耐力、自我效能与自主学习能力。

01 · 目标

长期目标：成人支架逐渐退出

最终不是 Lemon 更服从，而是越来越能自己判断和推进学习。

基础扎实与自动化

字词、计算、词句等基础可靠，减少低层认知负担。

方法、效率与耐力

会拆任务、找卡点、选方法、检查结果，并能面对适度困难。

兴趣、自我效能与自主

知道“我哪里不会、我有办法解决”，最终能自己回答学什么、怎么学、是否学会。

02 · 当前 Top 1

未来 6–8 周：在错误、困难和情绪出现时，不退出学习循环

核心不是“更听话”，而是逐渐形成稳定的自我监控、求助、纠错和恢复能力。

当前主循环

任务 → 小步启动 → 发现停顿 / 卡点 → 主动说出来 → 最小帮助 → 自己继续 → Verify → 完成结束

核心认知：事情出了问题 ≠ 我这个人有问题。做错一道题、需要帮助、被指出错误，都不等于“我不行”。

本阶段证据：启动时间、成人提醒次数、主动暴露卡点、出错或情绪后的 Resume。

02 · 当前问题

当前四个主要阻塞

不统一解释成“不自律”，分别看行为、技能、情绪与学习认知。

执行连续性

制定好任务后通常能较快开始，但过程中仍会停顿，需要逐渐减少成人提醒。

看：Interrupt 次数、独立工作时长
书写动作不稳定

中文笔顺；英文四线三格、字母上下位置、单词间距。

看：能否独立复现正确动作
错误与情绪绑定

做错题或被纠正时容易体验成“被指责”，随后出现烦躁或“我不会”的整体判断。

看：能否把错误具体化并恢复任务
主动暴露问题不足

已有主动提问的正向变化，但还要稳定成“我知道自己卡在哪里，并主动求助”。

看：Self-report 是否增加
03 · 当前处理

先减少摩擦，再训练完整学习闭环

能力训练嵌入真实作业与课程，不额外叠加一套“自律训练”。

1
成人先理顺任务

少数重点、明确边界、一次只看当前一项。

2
落到第一步

不是“认真一点”，而是明确现在具体做什么。

3
一次教一个核心动作

先试 → 找断点 → 示范 → 自己做 → 新任务验证。

4
进步换来支架减少

会了减少重复，能自己做就成人后退，完成后不临时加量。

当前两周重点
  • 保持必要学习质量，不自动加量。
  • 减少一处真实低价值负担，释放时间不立即换成新训练。
  • 观察课外抵触发生在哪个具体场景。
  • 任务已经清楚仍抵触时，检查课程本身而不是继续催。
  • 有限自主必须真实兑现。
04 · 各学科

教材是主线，能力结构是长期目标

不靠题量证明进步；围绕真实掌握和长期能力组织。

语文 · 人教四上

字词 → 积累 → 课文理解 → 阅读 → 表达写作
  • 字词关注认读、正确笔顺/字形、词义和易错点。
  • 阅读训练定位、证据和完整回答。
  • 写作先做到有内容、顺序清楚、有具体细节。
  • 当前书写重点是真实错字与笔顺，不大量罚抄。

数与运算 → 运算律 → 数量关系 → 几何空间 → 数据
