    复习

    学完一个单元，怎么复习

    语文重积累与表达，数学重理解与变式。只有确认单元学完、当天任务允许才选用；试行预算并非四年级平均用时。未核对视频完整口播，不把此方案冒充视频原话。

    01

    先看任务标尺，不先定一个“必须多快”

    待选任务
    尚无记录不把其他字数、题量或讲解条件的记录直接套用。
    由成人与 Lemon 确认参考是方向，约定应接得住当前能力。

    参考区间是本项目的试用估时，不是四年级平均水平、常模或达标线。没有同量实测，先建立基线，不自动催快。

    查看完整任务标尺与适用条件
    已学、常规任务；包含读题、思考、书写与自查。较长教学和约定休息另记。不按页数、字数线性推算。
    任务可比较的范围试用参考最低质量要求
    已知事实：500字约两小时，还不是完整基线

    家长反馈：约500字作文抄写，整件事耗时约120分钟。任务原文、难度、实际动笔、离题停顿和长讲解各占多少尚未记录。

    这条观察单独保留，不作为新测量，不用它推算100字用时。中文从较短段落起步；同等质量稳定后再增加任务量。英文按单词、行或短段计，不套中文500字。

    约定这次做多少、用多久、怎样算完成

    生成本次建议

    读取实际任务、同条件实测和当天课程。先给草案，不自动新增约定或改写记录。

    首次使用：把下方任务加入候选，用时可留空。每日例行内容未核实时会显示待确认。

    写明页码、文字来源或当天练习包。
    比较条件与截止要求
    同材料类型、密度与质量要求才比较；任务组改变则建立新基线。
    加入的是已有学习任务，不是额外的一套训练。

    开工前 5 分钟 · Lemon 自己做决定

    使用现有“计划、休息与收尾”预算，不再加一份训练；成人只在必要时提醒，最后让 Lemon 自己开始。

    1. 看清（1分钟）：今天有哪些已确认的任务？
    2. 排序（1分钟）：我决定先做哪项，为什么？
    3. 估量（1分钟）：这项约定多少分钟，做到什么算完成？
    4. 拆步（1分钟）：我现在能独立做的第一小步是什么？
    5. 启动（1分钟）：准备材料，先独立尝试，遇到卡点再求助。

    尚未确认本次任务；先在上方生成并采用约定。

    结束后继续使用现有“实测与反馈”记录质量、提醒次数和帮助程度，不新增打卡或“前额叶评分”。

    带入已有任务池、每日练习与课程作业

    旧任务的“预计分钟”只作旧预算，不冒充实测，也不自动认定已完成。填入本次范围、教学和完成标准后才加入约定。

    家长和家教：同一套计时、检查和认可方式

    开始前

    先看实际材料、必要性和难度。参考用时是方向，最近真实表现决定本次约定；没有数据先观察。成人掌握总量，Lemon 参与顺序和责任。

    执行中

    引导 → 一起试 → Lemon 自己完成小段 → 集中检查。真正不会就教，长讲解另记。一次只抓一个规范或一个独立行为，不逐字逐题打断。

    结束时

    同时看任务量、用时、质量和帮助。未达成先判断估量是否合理、知识是否会、过程在哪里中断；不直接归为态度差。

    下次

    同等质量下减少提醒、缩短用时或增加连续完成量，都可能是进步。先稳定，再只改一个维度。奖励照事先约定，不因进步加任务。
