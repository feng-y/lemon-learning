# 2026 秋季 6–8 周核心主题

## Top 1

帮助 Lemon 建立一个新的经验：

> **事情出了问题，不等于我这个人有问题。遇到任务、错误和不会，我仍然可以把具体问题说出来、获得一点帮助，然后继续。**

当前观察到的现象不是彼此独立的：不愿写作业、启动慢；做事容易烦和激动；错题或纠正容易体验成“在指责我”；随后容易说“我不会”；如果成人不反复追问，又不容易主动暴露卡点。平静沟通、让他知道安排并参与确认后，接受辅导的意愿会提高。

因此当前不把问题简单定义为“懒 / 不自律”，也不把目标定为“马上喜欢学习”。先改变学习中的循环：

`任务 → 小步启动 → 暴露卡点 → 处理具体问题 → 自己继续 → 完成 → 结束`

替代：

`任务 → 回避 → 催促 → 烦躁 → 出错 → 我不会 / 我被批评 → 更抗拒`

## 6–8 周希望看到的变化

1. 协商完成后，开始第一步的时间缩短。
2. 成人不用多次追问，Lemon 开始会说“我卡在这里 / 我不知道怎么开始 / 给我一个提示”。
3. 从“我不会”逐渐变成“这一题 / 这一步 / 这个字我还不会”。
4. 被指出错误后，即使不高兴，也能在较短时间内回到任务。
5. 完成约定任务后有可信的结束点，学习效率提高不会自动换来更多任务。

## 成人 / 家教执行规则

### 1. 学习前：先建立共同计划

用 3–8 分钟明确：今天必须完成什么；先做什么；分几段；什么时候休息；做到哪里结束。成人负责边界和难度，Lemon 参与顺序、困难和休息安排。沟通结束必须落到一个具体第一步。

不要说：“赶紧开始写作业。”

优先说：“我们已经定好了。现在只做第一步：拿出数学本，翻到第 23 页，看第一题。”

### 2. 任务中：少追问，训练主动暴露问题

建立三句固定求助语：

- “我不知道怎么开始。”
- “我做到这里不会了。”
- “给我一个提示。”

初期成人可以提醒使用，之后逐渐减少提醒。目标不是让 Lemon 硬撑，而是学会识别并表达自己的未知。

### 3. 错误出现：只处理事情，不评价人

固定结构：`发生了什么 → 卡在哪里 → 怎么处理 → 继续`。

优先说：

- “这里结果不对，我们找从哪一步开始不一样。”
- “前两步是对的，现在只看第三步。”
- “不是整题不会，是这里还没弄清楚。”
- “这个字的问题是笔顺，我们只改这一处。”

避免：

- “你怎么又错了？”
- “不是讲过了吗？”
- “你到底会不会？”
- “你就是粗心 / 不认真。”

### 4. 他觉得被指责：澄清，但不取消问题

可以说：“你觉得我刚才是在说你不好。我现在想处理的是这道题，不是在评价你。我们只看这一处。”

如果成人确实语气重了，可以直接承认：“刚才我的语气像在批评你，这个我调整；这道题的问题我们还是一起解决。”

不要为了避免情绪而停止正常纠错，也不要在情绪起来后进入长时间说教。

### 5. “我不会”：从整体判断拉回局部

不反驳“你明明会”，也不空泛安慰。只问：“从哪一步开始不知道？”

帮助 Lemon 形成：`我不会 → 具体哪里不会 → 最小帮助 → 自己完成下一步`。

### 6. 烦躁 / 激动：先识别原因，再做一个动作

- 不会 → 帮一个最小步骤；
- 任务看起来太多 → 只呈现当前一段；
- 累 → 按约定短休息；
- 单纯不想开始 → 不展开长谈，回到已经约定的第一小步。

目标不是“不能有情绪”，而是“情绪后还能继续”。

### 7. 完成：必须兑现结束

约定的任务完成并检查后就结束，不因为做得快临时加量。让 Lemon 真实体验：`效率提高 → 成人提醒减少 / 重复减少 / 自己时间增加`。

## 沟通原则

1. **先事实，后处理，不评价人格。**
2. **一次只说一个问题。** 不连续追问、连续纠错。
3. **问题具体化。** “这一笔 / 这一步 / 这一题”代替“你不会”。
4. **允许表达不喜欢。** 不喜欢作业不等于可以取消必要任务，但可以讨论顺序、帮助和结束点。
5. **给出的选择必须真实。** 选择后不把所有选项重新补回来。
6. **成人也受约束。** 不临时加任务；不把错误升级为人的评价；语气不合适时承认并调整。

## 每周只看 4 个行为信号

- **启动**：计划后多久开始第一步？
- **提醒**：完成过程中成人需要提醒多少次？
- **暴露问题**：能否主动说出具体卡点？
- **恢复**：出错或情绪起来后，多久 / 如何重新进入任务？

不以“今天乖不乖 / 自觉不自觉”作为评价。

## 阶段节奏

- **第 1–2 周**：成人先稳定自己的语言和流程；降低启动摩擦，观察触发点。
- **第 3–4 周**：强化“事情问题 ≠ 人的评价”，练固定求助语和具体化错误。
- **第 5–6 周**：减少提醒，让 Lemon 更多主动开始、报告卡点、恢复任务。
- **第 7–8 周**：在不同学科、不同成人和不同任务中验证是否能迁移。

这 6–8 周不同时启动新的“自律训练”“情绪训练”或大量额外题目。书写、语数英照常学习，但都服务于同一个主循环。
