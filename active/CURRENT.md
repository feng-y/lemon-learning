## 当前 Top 5

### 1. 学习负荷与课外课程体验：当前最高优先级

目标不是让 Lemon “马上喜欢学习”，而是先判断课外课程的抵触主要来自哪里。

优先观察四类摩擦：

1. **负担 / 时间被占满**：还没开始就反感，常问什么时候结束；
2. **难度 / 节奏不合适**：连续纠错、跟不上、跨度过大后明显受挫；
3. **重复 / 收益不清楚**：已经会的内容仍被多轮重复检查和练习；
4. **课堂方式 / 互动不合适**：只对某位老师、某类课堂或某种纠错方式特别抵触。

两周内先做一处真实减负：

- 有课外课的当天，**默认不再叠加同科家庭专项**；确有必要的短确认尽量并入原有学习时段；
- 同一目标避免“课堂检查 → 家教再查 → 家长回家再考”三次重复；
- 对抵触最明显、实际收益又不清楚的一项，优先**减频、缩短或暂停试行**；
- 释放出来的时间不立即换成另一项训练。

检查：必要学习质量是否保持，同时开始前和学习中的拉扯是否减少。

### 2. 任务组织：继续保留，但不解释所有问题

面对多个任务时，仍采用：

> **成人先帮忙梳理 → 一起排 1→2→3 → 一次只看当前一项 → 完成后进入下一项。**

逐渐让 Lemon 自己参与排序。

但如果任务已经清楚，仍持续对某门课明显抵触，则继续检查课程本身，不继续用“任务组织能力不足”解释。

检查：从看到任务到开始第一项需要多久；成人催促次数是否下降。

### 3. 学科主线：保持质量，不新增专项堆叠

学校正常学习和已有教材主线继续推进，但这两周不因为“最近有进步”而自动加量。

#### 语文
- 保留必要的字词、背诵、阅读和学校任务；
- 关键错字和真实薄弱点针对修复；
- 不把普通错误扩成大量罚抄或额外专项。

#### 数学
- 保持计算正确性、数感和问题解决的正常教学；
- 简单题稳定规范，复杂题先说卡点，不会题重新独立完成；
- 不用增加题量证明进步。

#### 英语
- PU3 / PEP 正常推进；
- 优先保证真实听说读写和词句使用；
- 课外课当天不默认再叠加完整的同科家庭训练。

统一检查：**掌握后是否可以减少重复、减少提醒或退出高频训练。**

### 4. 学习中的有限自主：选择必须真实可兑现

不把整个学习规划交给 Lemon，也不只给“先做哪个”的表面选择。

成人可以提供 2 个都可接受的真实选项，例如：

- 两项必要任务先做哪一个；
- 今天哪一项重复练习可以取消；
- 家教先帮他解决哪个最卡的问题；
- 约定的学习时段结束后，哪段时间明确不再安排学习。

原则：**给了选择就兑现，不在选择以后重新把所有任务补回来。**

检查：Lemon 是否更愿意进入已经约定好的必要学习；是否更愿意表达真实困难。

### 5. 进步要换来“支架减少”，而不是马上加任务

当前正反馈不只说“你做得不错”，而要让真实进步带来可感知的变化：

- 会了的内容减少重复；
- 能自己完成的步骤成人退后；
- 任务完成后有可信的结束点；
- 不因一次进步立即追加新任务。

反馈优先指向：

> “这一步以前需要提醒，这次你自己完成了。”  
> “刚才卡住以后你说清楚了哪里不会，所以我们只需要解决这一小步。”  
> “今天约好的部分完成了，到这里结束。”

检查：Lemon 是否逐渐感受到“我学会了 → 我可以更独立 / 少一点重复”，而不是“我学会了 → 马上有更多任务”。

## 本周 Top 3（2026-09-07 起）

### 1. 减少一处真实学习负担

- 把学校作业、课外课、家教、家庭专项和复习检查放在一起看；
- 选择一处抵触明显、收益不清楚的叠加项进行减频、缩短或暂停试行；
- 不用其他训练填满释放的时间。

结果只记：`未调整 / 已调整无明显变化 / 拉扯减少 / 学习质量受影响`。

### 2. 记录课外课程抵触发生的具体场景

不问“为什么总是不想学”，只记录最近的真实事件：

- 当时是什么课程 / 任务；
- 抵触发生在开始前、遇到困难后、连续纠错后，还是临近结束；
- Lemon 当时的原话；
- 调整任务量、难度、节奏或互动方式后是否恢复。

目的：区分负担、难度、重复和课堂方式，而不是给 Lemon 下结论。

### 3. 保持必要学习质量，不加码

- 学校必要任务正常完成；
- 成人继续使用清晰排序和 Short Lesson；
- 掌握的内容退出高频重复；
- 两周内不新增独立的“学习情绪训练”“自律训练”或额外题量计划。

结果只看：必要学习是否保持基本质量，以及成人推动是否减少。

## 每次 Short Lesson：15–25 分钟

一次只教会一小步：

1. **先理任务**：当前只做哪一项，什么时候结束；
2. **小目标**：结束时 Lemon 能做到什么；
3. **先试**：判断是不会、提醒后会，还是已经基本会；
4. **示范**：成人只示范一个核心动作或思路；
5. **练习**：模仿一个 → 自己一个 → 必要时小变式一个；
6. **检查**：换一个相近新任务，不问“懂了吗”；
7. **反馈**：明确指出原来哪里不会 / 不稳，现在具体哪里变会了；
8. **结束 / 退支架**：约定目标完成后停止；掌握后减少重复和成人介入。

成人介入顺序：

> **任务乱先理顺 → 等一下 → 一个提示问题 → 示范一步 → 必要时重新教。**

新增判断：如果任务清楚、知识也能完成，但持续抵触明显，先检查**负荷 / 课程形式 / 节奏 / 重复度**，不继续叠加催促。

不先把抵触归因为态度问题。
